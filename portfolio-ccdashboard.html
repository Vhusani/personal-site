Comment

This project involved collaboration among web designers, a frontend developer, and backend developers. My role encompassed both backend and frontend development. The backend was implemented using .NET 7 Web API (Dapper ORM), while the frontend was developed with Angular 16. I was responsible for initializing the frontend of the project, including setting up its structure. Additionally, I integrated the application with OAuth (Identity Server) to manage user profiles and authentication. The project featured multiple tabs, and I contributed to both the frontend and backend development for the Accounts and Laybuy tabs.
