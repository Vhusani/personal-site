In this project, I was responsible for developing a comprehensive system to help the company manage various operational aspects, such as tracking employee and customer details, managing company vehicles, and recording the daily kilometers driven by each car. The system also includes chart-based visualizations of the kilometers driven for each vehicle. This monolithic web application was entirely my independent effort, encompassing the definition of the project scope, application setup, frontend design and implementation, backend development, and database creation. The project is still in progress and has not yet been completed.
